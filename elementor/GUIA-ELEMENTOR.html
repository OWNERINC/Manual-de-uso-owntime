Own Time Home Club — Diretório Digital · Versão Elementor

Fase 1

Configuração Global (faça isso uma vez)

1

Fontes Google — Elementor › Site Settings › Custom Fonts ou Theme Style

Adicione as duas fontes via Google Fonts:

  • Cormorant Garamond — pesos 300, 400, 600 + itálicos
  • Inter — pesos 300, 400, 500
💡 Em Elementor › Site Settings › Theme Style › Typography, defina a fonte padrão do corpo como Inter e a fonte de títulos como Cormorant Garamond.
2

CSS Global — Elementor › Site Settings › Custom CSS

Abra o arquivo elementor-global.css desta pasta, copie todo o conteúdo e cole no campo Custom CSS.

⚠️ Faça isso antes de criar qualquer seção — o CSS precisa estar disponível para estilizar os widgets.
3

Código JS — Elementor › Site Settings › Custom Code

Abra elementor-custom-code.html, copie todo o conteúdo e cole em Custom Code › Before </body>.

Isso carrega: GSAP, ScrollTrigger, Lucide Icons e os scripts de animação.

4

Imagem do Hero — WordPress › Mídia

Faça upload de assets/images/hero-owntime.jpg na Biblioteca de Mídia do WordPress. Copie a URL gerada — você vai usar na seção Hero.

Fase 3

Animações de Reveal no Scroll

1

Como aplicar animação de entrada em qualquer widget

Clique no widget → Advanced › CSS Classes → adicione owntime-reveal.

O widget ficará invisível no carregamento e aparecerá suavemente quando o usuário rolar até ele.

2

Stagger — atraso entre múltiplos widgets

Para criar efeito em cascata (um elemento depois do outro), combine as classes:

Classe extraAtrasoUso
owntime-reveal0sPrimeiro elemento do grupo
owntime-reveal owntime-delay-10.09sSegundo elemento
owntime-reveal owntime-delay-20.18sTerceiro elemento
owntime-reveal owntime-delay-30.27sQuarto elemento
owntime-reveal owntime-delay-40.36sQuinto elemento
3

Alternativa: Elementor Motion Effects

Se preferir usar o sistema nativo do Elementor, em vez de owntime-reveal, vá em Advanced › Motion Effects › Entrance Animation e selecione Fade In Up. O resultado é muito parecido.

Fase 4

Checklist de Verificação

Antes de publicar, confirme:

  • ☐ Fontes Cormorant Garamond e Inter carregando corretamente
  • ☐ Hero: foto do empreendimento aparece com overlay escuro + glow verde
  • ☐ Hero: textos animam ao carregar (fade up em cascade)
  • ☐ Linha de scroll no hero encolhe ao rolar
  • ☐ Accordions de Facilities, Gastronomy e Concierge abrem/fecham
  • ☐ Ícones Lucide aparecem nos títulos dos accordions
  • ☐ Cards de Amenities: Spa com ícone e horário em dourado
  • ☐ Botão WhatsApp aparece após 12% de scroll
  • ☐ Mobile (375px): barra no rodapé · Desktop (1280px+): FAB circular
  • ☐ Link WhatsApp abre o chat corretamente
  • ☐ Nenhuma ocorrência de "timeshare", "multipropriedade" na página
  • ☐ Testar prefers-reduced-motion: todos os elementos visíveis sem animações
